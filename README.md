# Dark Pattern Blockers

Amazon Dark Pattern Blocker hides ads, upsells and pressure tactics with adjustable protections.

[![Amazon ADPB](badge.svg)](https://github.com/ExtraPotions/dark-pattern-blockers/releases/latest)

**Version 1.3.7** · [Install userscript](https://github.com/ExtraPotions/dark-pattern-blockers/releases/latest/download/amazon-dark-pattern-blocker.user.js) · [Release notes](CHANGELOG.md)

Install with Tampermonkey or Violentmonkey, then reload Amazon. Update the existing script to retain settings.

- Choose protections from a compact menu with accessible toggles and tap-friendly help.
- Temporarily reveal hidden items dimmed without changing saved protections.
- Compatible badges align together and follow their shared anchor.
- Drag the launcher to reposition it; use Escape to close settings.
