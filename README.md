# Amazon Dark Pattern Blocker

Userscript that strips common dark patterns on **amazon.com** / **www.amazon.com**.

Works with **[Violentmonkey](https://violentmonkey.github.io/)** (preferred), Tampermonkey, or any userscript manager.

## Install

1. Install a userscript manager (Violentmonkey recommended).
2. **[Install from latest release](https://github.com/ExtraPotions/velvet-crane-orbit/releases/latest/download/amazon-dark-pattern-blocker.user.js)**

All installs and manager update checks go through GitHub Release assets (`@downloadURL` / `@updateURL`), so they show up in the download stats above.

Browse releases: [github.com/ExtraPotions/velvet-crane-orbit/releases](https://github.com/ExtraPotions/velvet-crane-orbit/releases)

## What it blocks

- Prime upsells and checkout interstitials
- Urgency / scarcity tactics
- Subscribe & Save nudges
- Sponsored products and ad shelves
- Credit card and protection-plan upsells
- Rufus / AI promo chrome
- Amazon service and Business promos
- Frequently bought together / carousel clutter

Optional: auto-clip coupons, compact search results.

## Settings

Floating favicon button on the right (drag up/down). Orange switches = on. Changes apply live — no refresh needed for most toggles.
